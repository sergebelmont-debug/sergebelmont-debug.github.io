# sergebelmont.com

Site officiel de Serge Belmont : page d'accueil qui présente les deux jeux.

- Site statique (HTML + CSS), sans étape de construction.
- Polices hébergées sur le site (aucun appel à un service extérieur).
- Les jeux vivent dans leurs propres dépôts et sont servis sous ce domaine :
  - `/bubble-nostalgia/` : dépôt `bubble-nostalgia`
  - `/mots-fleches/` : dépôt `mots-fleches`

## Mise en ligne

Hébergé sur GitHub Pages (dépôt `sergebelmont-debug.github.io`, branche `main`).
Le domaine sergebelmont.com est relié par le fichier `CNAME` et la zone DNS chez OVHcloud.

## Modifier la page

- Texte : `index.html`
- Couleurs et mise en page : `styles.css` (variables en haut du fichier)
- Image d'aperçu des partages : `images/og-image.jpg` (1200 × 630)
